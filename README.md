# Call Center Performance Dashboard -- 2023

## Project Overview

This project is an interactive Microsoft Excel dashboard built to
analyze call center performance in 2023. It brings key performance
indicators (KPIs), call trends, representative-level performance,
customer ratings, and city-level data into one report.

## Dashboard Highlights

-   **KPI cards:** Calls, Amount, Duration, Average Rating, and Happy
    Callers.
-   **Monthly call trend:** Compare call activity across the months of
    the year.
-   **Weekday analysis:** Review call distribution across Sunday to
    Saturday.
-   **Caller demographics:** Compare female and male callers across
    Cincinnati, Cleveland, and Columbus.
-   **Customer ratings:** View the distribution of ratings from 1 to 5.
-   **Representative performance:** Compare calls and amount by
    representative (R01--R05).
-   **Detailed report:** Review customer-level amounts by city and
    representative.
-   **Interactive filtering:** Use the representative slicer to filter
    the dashboard.

## Tools and Techniques

-   Microsoft Excel
-   PivotTables and PivotCharts
-   Dashboard design and data visualization
-   Interactive slicers and KPI reporting

## How to Use

1.  Download or clone this repository.
2.  Open the Excel workbook (`.xlsx`) in Microsoft Excel.
3.  Use the representative slicer to filter the dashboard.
4.  Review the KPI cards and charts to explore call center performance.
